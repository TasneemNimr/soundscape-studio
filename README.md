# 🎙️ SoundScape — Premium Podcast Studio

A modern, fully responsive, multi-page web application designed for podcast creators and audio enthusiasts. Built with pure HTML5, CSS3, and JavaScript utilizing the Web Audio API.

---

## 🌟 Key Features

* **📊 Main Studio & Visualizer:** Real-time audio spectrum analysis and master engine controls using the Web Audio API.
* **🎛️ Interactive Soundboard:** Quick-access sound pads with synthesized audio effects for live podcast production.
* **🌊 Ambient Mixer:** Multi-channel ambient noise generator (Rain, Waves) with customizable audio faders.
* **📁 Recordings Library:** Persistent audio recording and playback system powered by Base64 encoding and LocalStorage.
* **🌓 Dark & Light Themes:** Instant theme switching with smooth CSS variables transition.
* **🌐 Multilingual Layout:** Dynamic LTR/RTL support.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Custom Properties)
* **Scripting:** Vanilla JavaScript (ES6+, Web Audio API, MediaRecorder API)
* **Architecture:** Multi-Page Application (MPA) with separation of concerns.
